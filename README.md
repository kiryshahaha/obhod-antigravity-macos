# Antigravity Unlocker — Версия для macOS

Адаптация Antigravity Unlocker под macOS (Apple Silicon M1/M2/M3/M4 и Intel x86-64) с возможностью ввода и подключения своего HTTP-прокси.

## Что делает программа (Логика приложения)

Логика работы полностью соответствует оригинальному проекту:
1. **Патч бинарников клиента (`language_server`, `agy`)**:
   - `ineligible` → `inexigible` (снимает ошибку 400 и проверку региона аккаунта Google).
   - `https_proxy` → `AG_LS_PROXY` (направляет трафик языкового сервера на локальный прокси, не затрагивая глобальный `HTTPS_PROXY` в системе).
   - Выполняет ad-hoc переподпись бинарников через `codesign --force --deep -s -` (на macOS это необходимо, чтобы система не блокировала изменённые файлы Mach-O).
2. **Локальный прокси (порт `127.0.0.1:53129`)**:
   - Слушает локальный порт и перехватывает CONNECT-запросы от Antigravity.
   - Запросы к серверам Google (`cloudcode-pa.googleapis.com`, `daily-cloudcode-pa.googleapis.com`) уводит через ваш **HTTP-прокси** с Basic-авторизацией.
   - Все остальные запросы (авторизация в аккаунте, скачивание пакетов, внешние сервисы) идут напрямую, не ломая TLS и не требуя сторонних сертификатов.
3. **Системное окружение на macOS**:
   - Экспортирует переменную `AG_LS_PROXY="http://127.0.0.1:53129"` через `launchctl setenv` (для программ, запускаемых из Finder/Dock) и прописывает в `~/.zshrc` (для терминалов).

## Быстрый запуск на Mac

1. Откройте терминал в папке `mac`:
   ```bash
   cd mac
   bash launch.sh
   ```
   *(Или просто дважды кликните по файлу **`launch.command`** в Finder).*

2. В открывшемся **TUI-меню**:
   - Выберите **`[1]`** и введите ссылку вашего HTTP-прокси:
     ```text
     http://username:password@proxy.example.com:8080
     ```
     *(Поддерживаются форматы с `http://`, `https://`, логин:пароль@хост:порт или хост:порт без пароля).*
   - Программа сразу проверит доступность серверов Google через этот прокси.
   - Выберите **`[3]` («Включить всё»)**:
     - Пропатчатся бинарники в `/Applications/Antigravity.app`.
     - Запустится служба локального прокси на `127.0.0.1:53129`.
     - Установятся системные переменные окружения.
3. Перезапустите Antigravity и напишите запрос в чат — модель ответит без ошибки 400.

## Доступные пункты меню TUI

- **`[1] Ввести ссылку своего HTTP-прокси`** — ввод ссылки вида `http://username:password@proxy.example.com:8080`.
- **`[2] Проверить работу прокси`** — отправляет тестовый TLS-запрос к `daily-cloudcode-pa.googleapis.com` через ваш прокси.
- **`[3] Включить всё`** — автоматически патчит клиент, запускает локальный прокси и настраивает переменные окружения.
- **`[4] Выключить всё`** — останавливает локальный прокси, сбрасывает переменные окружения и восстанавливает оригинальные файлы Antigravity.
- **`[5] Запустить локальный прокси`** — запускает локальный прокси в фоне на `127.0.0.1:53129`.
- **`[6] Остановить локальный прокси`** — останавливает фоновый процесс прокси.
- **`[7] Патчить Antigravity`** — только патч бинарников `language_server` и `agy` с переподписью `codesign`.
- **`[8] Восстановить оригиналы`** — откат изменений из резервных копий `.ag_backup`.
- **`[9] Удалить сохранённый прокси`** — очищает файл конфигурации `upstream.txt`.
- **`[0] Выход`** — выход из меню (фоновый прокси продолжит работать).

## Запуск из командной строки (CLI)

Программу также можно вызывать без интерактивного меню:

- Задать прокси и протестировать:
  ```bash
  python3 ag_unlocker.py --proxy "http://username:password@proxy.example.com:8080"
  ```
- Запустить только фоновый прокси-демон:
  ```bash
  python3 ag_unlocker.py --daemon
  ```
- Только пропатчить Antigravity:
  ```bash
  python3 ag_unlocker.py --patch
  ```
- Откатить патч:
  ```bash
  python3 ag_unlocker.py --unpatch
  ```

## Где хранятся настройки

- Файл прокси: `~/.local/share/agunlocker/upstream.txt`
- PID локального прокси: `~/.local/share/agunlocker/proxy.pid`
- Логи: `~/.local/share/agunlocker/mac_unlocker.log`
