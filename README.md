# Antigravity Unlocker — Версия для macOS

Адаптация Antigravity Unlocker под macOS (Apple Silicon M1/M2/M3/M4 и Intel x86-64) с поддержкой подключения своего HTTP-прокси, обхода ошибки 400 и **входа в аккаунт Google из-под санкций**.

---

## Что делает программа (Логика приложения)

Логика работы полностью перенесена и адаптирована из основного проекта:

1. **Обход региональной ошибки 400 (патч бинарников Mach-O)**:
   - `ineligible` → `inexigible` в бинарниках `language_server` (снимает региональную блокировку и проверку аккаунта Google).
   - `https_proxy` → `AG_LS_PROXY` (направляет запросы Language Server на локальный прокси без вмешательства в глобальный `HTTPS_PROXY` системы).
   - Автоматическая ad-hoc переподпись через `codesign --force --deep -s -` (требуется на macOS для запуска модифицированных исполняемых файлов).

2. **Вход в аккаунт Google из-под санкций (JS-патчи IDE и расширения)**:
   - Патч `out/main.js`: разблокирует процесс авторизации (`loadCodeAssist`, `onboardUser` со стандартным/бесплатным тиром, подстановка `userTier: { id: "pro", description: "Pro" }`, вызов `AUTH_SUCCESS`).
   - Патч `extensions/antigravity/dist/extension.js`: задает fallback-статус пользователя при блокировке `UserStatus` со стороны Google.
   - Патч `dist/main.js` (для Electron shell): перехватывает ошибки `ineligible` при входе.

3. **Локальный шлюз-прокси (порт `127.0.0.1:53129`)**:
   - Слушает локальный порт и выборочно маршрутизирует трафик Antigravity.
   - Запросы к серверам Google (`cloudcode-pa.googleapis.com`, `daily-cloudcode-pa.googleapis.com`, `oauth2.googleapis.com` и др.) уходят через ваш **HTTP-прокси** с Basic-авторизацией.
   - Все остальные запросы (сторонние расширения, веб-сокеты, пакетные менеджеры) идут напрямую на максимальной скорости и без вмешательства в TLS.

4. **Интеграция с macOS и settings.json**:
   - На современных версиях macOS (Ventura, Sonoma, Sequoia) оконные приложения из Finder/Dock часто изолированы от `~/.zshrc`.
   - Программа автоматически прописывает `"http.proxy": "http://127.0.0.1:53129"` в `~/Library/Application Support/Antigravity/User/settings.json`, экспортирует `AG_LS_PROXY` через `launchctl setenv` и предоставляет скрипт прямого запуска с переменными окружения.

## Быстрый запуск на Mac

1. Откройте терминал в папке `mac`:
   ```bash
   cd mac
   bash launch.sh
   ```
   *(Или дважды кликните по файлу **`launch.command`** в Finder).*

2. В открывшемся **TUI-меню**:
   - Нажмите **`[1]`** и введите ссылку вашего HTTP-прокси:
     ```text
     http://username:password@proxy.example.com:8080
     ```
     *(Поддерживаются форматы `http://`, `https://`, `user:pass@host:port` или `host:port` без пароля).*
   - Программа сразу протестирует связь с серверами Google через прокси.
   - Нажмите **`[3]` («Включить всё»)**:
     - Пропатчатся бинарники (ошибка 400).
     - Применятся патчи входа в аккаунт под санкциями.
     - Запустится фоновая служба прокси на `127.0.0.1:53129`.
     - Настройки запишутся в `settings.json` и системное окружение.
   - Нажмите **`[4]` («Запустить Antigravity с прокси»)** или запустите файл **`launch_antigravity.command`**.

3. Теперь можно полноценно авторизоваться в Google-аккаунте и отправлять запросы в Antigravity без региональных ошибок.

## Пункты меню TUI

- **`[1] Ввести ссылку своего HTTP-прокси`** — сохраняет прокси в `upstream.txt` и проверяет подключение.
- **`[2] Проверить работу прокси`** — отправляет тестовый TLS-запрос к Google через ваш прокси.
- **`[3] Включить всё`** — комплексная активация: патч 400 + патч входа в аккаунт + настройка `settings.json` + запуск локального прокси.
- **`[4] Запустить Antigravity с прокси`** — запуск Antigravity с гарантированной передачей всех переменных прокси-окружения.
- **`[5] Разблокировать вход в аккаунт из-под санкций`** — отдельное применение патчей JS для входа в Google-аккаунт.
- **`[6] Выключить всё`** — откат всех патчей (бинарники Mach-O и JS), очистка `settings.json`, остановка прокси.
- **`[7] Перезапустить локальную службу прокси`** — перезапуск службы на `127.0.0.1:53129`.
- **`[8] Остановить локальную службу прокси`** — выключение службы без отката патчей.
- **`[9] Восстановить оригиналы всех файлов`** — полный откат бинарников и JS-файлов из резервных копий `.ag_backup`.
- **`[D] Удалить сохранённый прокси`** — удаление данных прокси из конфигурации.
- **`[0] Выход`** — выход из меню (служба прокси остаётся работать в фоне).

## Использование из командной строки (CLI)

- Сохранить и протестировать прокси:
  ```bash
  python3 ag_unlocker.py --proxy "http://user:pass@proxy.example.com:8080"
  ```
- Патч бинарников (ошибка 400):
  ```bash
  python3 ag_unlocker.py --patch
  ```
- Патч входа в аккаунт под санкциями:
  ```bash
  python3 ag_unlocker.py --patch-account
  ```
- Откат всех бинарных изменений:
  ```bash
  python3 ag_unlocker.py --unpatch
  ```
- Откат патчей аккаунта:
  ```bash
  python3 ag_unlocker.py --unpatch-account
  ```
- Запуск локального шлюза-прокси в фоновом режиме:
  ```bash
  python3 ag_unlocker.py --daemon
  ```

## Где хранятся файлы и резервные копии

- Конфигурация прокси: `~/.local/share/agunlocker/upstream.txt`
- PID локальной службы: `~/.local/share/agunlocker/proxy.pid`
- Лог-файлы: `~/.local/share/agunlocker/mac_unlocker.log`
- Бэкапы оригиналов создаются рядом с каждым файлом с суффиксом `.ag_backup` перед внесением любых изменений.
